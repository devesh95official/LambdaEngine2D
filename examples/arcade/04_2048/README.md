# 2048

Slide the tiles on a 4x4 board and merge equal ones. Reach 2048 to win, then keep going if you
like.

Controls: arrows/WASD or a mouse drag slide, Z/U/Backspace undo one move, R/N start a new game,
Enter or Space start and continue.

```sh
build/release/examples/arcade/04_2048/g2048  # --bot to watch, --headless --bot --frames 3000 for a summary
```
