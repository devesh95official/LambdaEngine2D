# Asteroids

Vector Asteroids: wrap-around space, rocks that split, waves, and an extra ship every 10,000
points. Large rocks are 20 points, medium 50, small 100.

Controls: Left/Right or A/D turn, Up/W or the right mouse button thrust, Space, J or the left
mouse button fire (hold to auto-fire), Enter starts.

```sh
build/release/examples/arcade/07_asteroids/asteroids  # --bot to watch, --headless --bot --frames 3000 for a summary
```
