# Missile Command

Protect six cities and three bases from falling warheads. From wave 2 some of them split in three.

Controls: the mouse or WASD/arrows aim, a left click, Space or Enter fires from the nearest base,
1 2 3 or Z X C fire from the left, centre or right base.

```sh
build/release/examples/arcade/08_missile/missile  # --bot to watch, --headless --bot --frames 3000 for a summary
```
