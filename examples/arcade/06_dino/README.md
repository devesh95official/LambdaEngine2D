# Dino Runner

Endless desert runner. Jump the cacti and low birds, duck under the higher ones. It speeds up as
you go, and day turns to night every 700 points.

Controls: Space, Up, W or a left click jump (hold for higher), Down/S ducks or drops faster in
the air, Space or Enter start and restart.

```sh
build/release/examples/arcade/06_dino/dino  # --bot to watch, --headless --bot --frames 3000 for a summary
```
